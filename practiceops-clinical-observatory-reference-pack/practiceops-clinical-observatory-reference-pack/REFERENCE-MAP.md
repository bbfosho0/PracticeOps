## Source-of-truth order

1. These images define visual ambition and composition.
2. The application data model defines content and functional behavior.
3. Production Angular, CSS, SVG, Canvas, and optional WebGL define the final browser result.
4. Figma remains a structural blueprint, not the fidelity ceiling.

## Non-negotiable direction

- Near-black obsidian and graphite spatial canvas
- Cyan and cobalt telemetry, ultraviolet intelligence, green success, amber/coral risk
- Strong editorial scale and one dominant operational focal point
- Integrated instruments rather than generic rounded card grids
- Selective shader language, never constant visual noise
- Purposeful motion with reduced-motion and static fallbacks
- Dense but legible operational information
